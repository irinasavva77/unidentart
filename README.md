# UniDentArt — Dental Appointment Booking System

## Overview

UniDentArt is a web application developed as my Bachelor's thesis in Applied Informatics. The project focuses on helping patients explore dental clinic services and book appointments online.

## Key Features

- Dental clinic information and service pages
- Online appointment booking
- Selection of a service, date, time, and doctor
- Form validation
- Prevention of double booking through appointment slot availability checks
- Responsive user interface for different screen sizes

## Testing

I manually tested the application using different scenarios, including:

- Form validation and user input
- Mobile layout and responsiveness
- Appointment booking flow
- Availability of booked time slots and prevention of double booking
